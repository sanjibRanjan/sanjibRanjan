## 🚀 Featured Projects

### RAG Pipeline — AI Document Q&A System
`Python` `Node.js` `HuggingFace` `ChromaDB` `OpenAI` `Anthropic Claude` `Gemini` `Firebase` `React`

- Built a production RAG system supporting PDF and TXT ingestion with HuggingFace sentence-transformer embeddings and ChromaDB vector search.
- Added a **Fast Mode** (disabling query rewriting and LLM re-ranking) that cut response latency **5–10x** on routine queries.
- Integrated multi-LLM runtime switching (GPT, Claude, Gemini), Firebase multi-tenant auth with JWT, GDPR data-export/deletion, and a ChatGPT-style React UI with drag-and-drop upload.

---

### Cricket Betting Agent — Real-Time AI Platform
`Node.js` `Express.js` `SportsBex API` `REST API` `JavaScript`

- Architected a modular backend (Fetcher → Analyzer → Generator) integrating the SportsBex API for live match data, run-rate calculation, and confidence-scored prediction generation.
- Exposed live-match, match-detail, and health-check endpoints with configurable rate limiting and structured JSON responses.

---

### MediSense — Production Medical AI Model
`Python` `PyTorch` `scikit-learn` `FastAPI` `HuggingFace` `Docker`

- Trained and fine-tuned a supervised ML classification model on structured medical datasets with feature engineering, cross-validation, and experiment tracking to reach clinical prediction accuracy.
- Deployed as a FastAPI inference service with input validation and confidence scoring; containerised with Docker and HuggingFace transformers for NLP-based feature extraction.

---

### CRE Intelligence Pipeline — AI-Powered Real Estate Platform
`Python` `Google Gemini` `Qdrant` `Streamlit` `Docker` `Pydantic` `BeautifulSoup4` `Plotly`

- Built a multi-source ingestion pipeline (RSS, web scraping, REST API, CSV/XLSX) normalising 6 data sources into a unified Pydantic v2 schema; batch-enriched via Gemini for summarisation, market-sector classification, and NER.
- Implemented a Semantic RAG search engine (Sentence-Transformers + Qdrant cosine similarity) and a cross-source intelligence layer; surfaced via an interactive Streamlit dashboard with Plotly charts.
